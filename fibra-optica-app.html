Casi todo lo que viaja entre continentes —este mensaje incluido— va como un rayo de luz rebotando sin parar dentro de un hilo de vidrio. El fenómeno que lo permite es la reflexión total interna.

Laboratorio: el ángulo lo es todo

Movés el ángulo con el que la luz golpea la pared del núcleo. Si el ángulo es lo bastante rasante, la luz no puede salir: rebota entera. Si no, se refracta y escapa hacia el revestimiento.

✓ REFLEXIÓN TOTAL INTERNA
Ley de Snelln₁·senθ₁ = n₂·senθ₂
Ángulo críticoθc = arcsen(n₂ / n₁)
θ₁ = 85.0°
θc = 80.6°
n₁ = 1.480
n₂ = 1.460
Condición: θ₁ ≥ θc → reflexión total

Este mismo principio es la base de Tecnología de las Comunicaciones (atenuación, fibra óptica, ondas) y el punto de entrada a Electromagnetismo (la luz como onda electromagnética).

Datos del caso real: cable submarino Firmina (Google/Telxius), Las Toninas (Buenos Aires) ↔ Myrtle Beach (Carolina del Sur). Estimación de tráfico global: Unión Internacional de Telecomunicaciones (UIT), 2026.
